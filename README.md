# پالتینو (Palettino)

سیستم دیزاین اتوماتیک پلت رنگی — دوزبانه (فارسی/انگلیسی).
یک رنگ، اسم یا موضوع بده و **۶ پالت هماهنگ با رنگ‌های مکمل** بگیر: **۳ روشن + ۳ دارک**، با پیش‌نمایش زنده و کدهای hex قابل‌کپی.

- دامنه: https://paletteeno.yaldajahanshahi.ir
- استک: **Next.js 16 + React 19 + Tailwind v4** (static export، بدون سرور)
- طراحی و توسعه: [YJ19](https://yaldajahanshahi.ir)

## قابلیت‌ها
- ورودی: اسم رنگ (دیکشنری fa/en)، color picker، توضیحات، یا انتخاب **موضوع/کاربرد** (سایت، بنر، اپ، پوستر…)
- **پیشنهاد خودکار بر اساس موضوع** وقتی رنگ نداری (هر بار خروجی متفاوت)
- خروجی همیشه **۳ روشن + ۳ دارک** با **اکسنت مکمل** واقعی
- هر کارت در **قابِ متضاد** (روشن روی تیره، دارک روی روشن)، با شماره‌ی سراسری
- **بازآفرینی/ترکیب**: پالت‌های تازه، بازآفرینی از یک شماره، یا ترکیب چند پالت — با حفظ تاریخچه
- سوییچ زبان (fa/en) + جهت RTL/LTR، ذخیره در localStorage
- CTA شناور با کادر ناوبری بین بخش‌ها

## توسعه
```
pnpm install
pnpm dev
```

## ساخت و استقرار
خروجی static در `out/`. راهنمای کامل در **[DEPLOY.md](./DEPLOY.md)**.
```
pnpm build
```

## ساختار
```
app/          layout + page (کل UI)
components/    PaletteCard (کارت پیش‌نمایش دوزبانه)
lib/
  colors.ts     ریاضیات رنگ، کنتراست WCAG، normalize
  dictionary.ts دیکشنری اسم رنگ fa/en + پارسر
  generate.ts   استراتژی‌های هارمونی/مکمل، بازآفرینی، ترکیب، پیشنهاد موضوع (دوزبانه)
  topics.ts     موضوعات + نمونه‌متن کارت (fa/en)
  i18n.ts       دیکشنری کامل UI (fa/en)
  engine.ts     موتور تولید سمت‌کلاینت (نسخه‌ی static)
```
